포스트맨을 사용하여 JWT(JSON Web Token)를 요청 헤더에 추가하는 방법은 다음과 같습니다:

Authorization 헤더를 설정: JWT를 요청의 Authorization 헤더에 추가합니다.
Bearer Token으로 JWT 설정: JWT를 Bearer 토큰 형식으로 설정합니다.
아래는 이러한 단계를 상세히 설명하는 방법입니다:

Authorization 헤더 설정:

포스트맨을 열고 요청을 생성 또는 열어줍니다.
요청을 선택한 후, 우측 상단에 있는 Headers 탭을 클릭합니다.
헤더를 추가하려면 키(Key)에 "Authorization"을 입력하고, 값(Value)에 "Bearer <JWT 토큰>"을 입력합니다. 여기서 "<JWT 토큰>" 자리에 실제 JWT 토큰을 넣어야 합니다.
Bearer Token으로 JWT 설정:

포스트맨을 열고 요청을 생성 또는 열어줍니다.
요청을 선택한 후, 우측 상단에 있는 Authorization 탭을 클릭합니다.
Type 드롭다운 메뉴에서 "Bearer Token"을 선택합니다.
Token 필드에 실제 JWT 토큰을 입력합니다.
이제 위의 단계를 따라 JWT를 포스트맨의 헤더에 추가하면, 해당 요청에서 JWT 인증을 사용할 수 있습니다. 이렇게 JWT를 포스트맨에 추가하면 서버에 요청을 보낼 때 해당 토큰을 함께 전송하여 인증에 활용할 수 있습니다.
