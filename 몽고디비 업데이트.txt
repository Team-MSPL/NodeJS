MongoDB는 featureCompatibilityVersion 이슈 때문에 **순차적 업그레이드(4.2→4.4→5.0→6.0)**가 필요합니다.
반드시 4.4나 5.0 버전에서 정상 구동 후, featureCompatibilityVersion을 변경하고 6.0으로 올려야 합니다.

4.4 -> 5.0

백업 먼저

sudo systemctl stop mongod

//libssl1.1 수동 설치 (Ubuntu 22.04)
wget https://launchpad.net/ubuntu/+archive/primary/+files/libssl1.1_1.1.1f-1ubuntu2.16_amd64.deb
sudo dpkg -i libssl1.1_1.1.1f-1ubuntu2.16_amd64.deb

wget -qO - https://www.mongodb.org/static/pgp/server-5.0.asc | sudo apt-key add -
echo "deb [ arch=amd64 ] https://repo.mongodb.org/apt/ubuntu bionic/mongodb-org/5.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-5.0.list
sudo apt update

sudo apt install -y mongodb-org=5.0.26 mongodb-org-server=5.0.26 mongodb-org-shell=5.0.26 mongodb-org-mongos=5.0.26 mongodb-org-tools=5.0.26
// 중간에 뭐 물어보면 y 말고 n !! conf 파일 관련

sudo apt --fix-broken install
mongo --version
mongod --version
sudo systemctl start mongod
sudo systemctl status mongod

//임시로 conf 쪽 인증 끄기 - 아래 주석처리
sudo nano /etc/mongod.conf

security:
  authorization: enabled


//fcv 올리기 (중요)
mongo
use admin
db.adminCommand({ setFeatureCompatibilityVersion: "5.0" })
db.adminCommand({ getParameter: 1, featureCompatibilityVersion: 1 })
-> 5.0 나와야해

6.0

sudo rm /etc/apt/sources.list.d/mongodb-org-5.0.list
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64 ] https://repo.mongodb.org/apt/ubuntu bionic/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list
sudo apt update


sudo apt install -y mongodb-org=6.0.12 mongodb-org-server=6.0.12 mongodb-org-shell=6.0.12 mongodb-org-mongos=6.0.12 mongodb-org-tools=6.0.12
// 중간에 뭐 물어보면 y 말고 n !! conf 파일 관련
